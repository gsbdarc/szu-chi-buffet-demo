# Buffet browser demo

[Play the buffet](https://gsbdarc.github.io/szu-chi-buffet-demo/) · [Experiment Builder](https://gsbdarc.github.io/szu-chi-buffet-demo/builder.html)

A desktop browser preview of the buffet study prototype. Open the link in current Chrome; Unity is not required.

Click **Start choosing**. **Look around / L** enables mouse-look, **Esc** restores the cursor, and **R** centers the view. Click a distant food to visit; click again after arrival to serve. **A / D** or **Previous / Next** moves along the counter. **Undo last** returns a serving. **Finish** confirms the plate.

Use **Export JSON** to download your choices. The demo does not upload choices to a study server. **Restart** starts a fresh plate. Phones/tablets and survey embedding have not been tested.

This repository contains the compiled website only. See [asset credits](CREDITS.md).

Researchers can drag foods into order, save named conditions, preview the game, and copy fixed participant links. Drafts save in this browser; Export file backs up all conditions and Import file opens them on another computer. Participant links retain their setup after later edits. Stock, serving sizes and plate capacity remain fixed in this iteration.

Results use schema version 3, including condition identity, exact menu/order and fixed settings, catalog/build versions, and a preview/participant marker. Assignment is manual through separate condition links. There is no server collection, login, or shared project database.
